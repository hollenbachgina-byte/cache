# cache

A Flask app for passive purchase capture and personal inventory value tracking. CS50 final project.

- Live: https://cache-77z1.onrender.com
- Build spec: [`CLAUDE_CODE_BUILD_SPEC.md`](CLAUDE_CODE_BUILD_SPEC.md)

## Known limitation

This app is hosted on Render's free tier, which spins down after a period of inactivity. The first request after idle can take up to ~1-2 minutes while the server restarts — this is expected behavior, not a bug.
